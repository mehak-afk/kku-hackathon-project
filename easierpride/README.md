# EasierPride — أبها على مهل

A bilingual Arabic-and-English, photo-rich guide for showing visiting friends the Abha and Asir places locals love: misty mountains, warm food, and living heritage.

## Features

- 10 curated places across Nature, Food, and Heritage.
- Interest and best-month filters.
- Arabic/English language toggle with RTL support.
- A three-stop **Plan my day** suggestion: morning, lunch, and evening.
- Google Maps links for every place.

## Run it

1. Open this `easierpride` folder.
2. Double-click `index.html`.
3. No install, account, server, or build step is required.

The guide loads all code and photos locally. The only external destinations are the intentional Google Maps links the visitor opens.

## Demo path

1. Tap **طبيعة / Nature**.
2. Browse the cards and select a month.
3. Tap **افتح في الخرائط / Open in Maps**.
4. Tap **خطّط يومي / Plan my day** for a three-stop itinerary.
5. Use **إعادة الدليل التجريبي / Reset demo guide** to restore built-in choices.

## Privacy

The guide stores only language, filter, month, and itinerary preferences in the browser’s localStorage. Nothing is submitted or sent to a server.
